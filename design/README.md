# MedQuick Design Pack (DA-2)

This folder is the **design deliverable**, reverse-engineered from the running MERN code (`front/` + `back/`), then mapped to requirements.

## Pipeline

```
Actual Code
  → Design Principles
  → Architecture
  → Requirements → Design Mapping
  → UI Design
  → Design Decisions
  → Scalability
  → Cost Estimation
  → ProjectLibre (WBS / Gantt)
  → Software Design Document
  → README + GitHub
  → FINAL DA-2
```
